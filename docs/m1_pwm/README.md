# M1_PWM 输出验证 ## 目标 TIM3_CH1 (PA6) 输出 10kHz PWM，占空比 20%↔50% 每 2 秒切换

## 配置
- PSC=71, ARR=99 → 72MHz/72/100 = 10kHz
- CCR1 由寄存器直写 TIM3->CCR1 控制

## 验证结果（逻辑分析仪 24MHz 采样）
- 实测频率：10.0 kHz
- 50% 相位高电平宽度：50µs
- 20% 相位高电平宽度：20µs
- 500kHz/1MHz 采样捕获到占空比切换瞬间（见 transition 截图）

## 踩坑记录
- LA 克隆机驱动：出厂固件走 Saleae Logic 驱动路径
- USB 重枚举时 Windows 会播放"弹出"音效，属正常固件上传
