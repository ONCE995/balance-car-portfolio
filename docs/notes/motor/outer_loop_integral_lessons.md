# 串级外环积分教训:大误差下必须管住积分

> 前置:M5 位置-速度串级(本笔记的实验平台)见
> milestones/m5_position_loop/README.md
> 结论先行:**串级外环(位置环)用纯 P**；要加 I 必须做积分分离

## 1. 现象(目标 90° 阶跃，同一速度环内环，只改外环配置)

| 配置 | 现象 |
|---|---|
| 纯 P(Kp=1.67，Ki=0) | 不到 1 s 到位，无过冲，稳态误差 0.05°~0.19° |
| P+I(Ki=0.02,Kaw=0) | 快，但明显过冲，冲过目标后慢慢回落 |
| P+I+KAW(Ki=0.02,Kaw=0.3) | 短时间落在 ~75.45°，随后极慢上爬；误差还有十几度时输出已 ≈0 |

## 2. 机理

### 2.1 积分项 及 反计算法 适用场景

积分项的本职是**末端补足**稳态误差;反算抗饱和(KAW)的本职是**修剪**积分。
两者都是给"误差不大、偶尔短暂饱和"的**收尾阶段**设计的。

位置环恰好是反面——**开机全速**:
- 起步误差 90°,输出立即顶满 25 rpm；
- 满速 25 rpm 每 10 ms 只走 **1.5°**(25/60×0.01×360),从 90° 冲到退饱和
  边界 30° 要约 40 个周期 = **0.4 s 连续饱和**——反算全程在抽积分。

饱和期每个周期(e=90° 时):

| 积分的变化 | 数值 |
|---|---|
| 累积项 `error·dt` | +0.9 |
| 反算项 `Kaw·(out−out_unsat)/Ki = 0.3×(25−150.3)/0.02` | **−1879.5**(≈2000 倍) |

关键点：**一个周期就砸穿下限,钉死在 −1250**(int_max = out_max/Ki = 25/0.02)，比例项则需要抵消了积分项带来的最大负值后还能继续保持满速状态

### 2.2 锁：两个限幅
说明：这里说的饱和指顶满out输出的限幅

| 锁 | 对象 | 边界 | 说明 |
|---|---|---|---|
| 输出限幅 | out | out_unsat vs ±25 | 反算项只在它生效期间非零;**"退饱和"指它** |
| 积分限幅 | 状态 I | ±1250 | 只冻结状态值,不决定当拍输出 |

因此 **"I 在 ±1250 以内" ≠ "退饱和"**。反例(e=40°):真实状态 I=−1250
没动过——平衡点 I_eq≈−2089 仍在界外,每周期增量 −251.6,继续钉死；
即便假设 I=−627,out_unsat = 1.67×40 + 0.02×(−627) = 54.26 > 25,照样饱和。
**解锁与否不看 I 的当前值,看平衡点是否进界。**

### 2.3 退饱和边界 e≈30°  最后一段只能"爬"

I 钉在 −1250 期间:

    out_unsat = Kp·e + Ki·I = 1.67e − 25        ← −25 = Ki·(−int_max)，积分钉在下限时的贡献
    仍饱和 ⟺ 1.67e − 25 ≥ 25                    ← 后一个 25 = out_max
            ⟺ Kp·e ≥ 2·out_max ⟺ e ≥ 29.9°      ← 退饱和误差角度

对照纯 P:满速区间是 `Kp·e ≥ out_max`，即 **e ≥ 15°**(该处 I_eq 恰好过零)。
所以 **15°~30° 这段,纯 P 还在满速冲，带 KAW 的版本输出已提前衰减**——
这就是波形里 70 多度之后"只能爬"的直接原因。

### 2.4 最终卡点:out=0 线 + 静摩擦死区 → 75°

退出饱和后,(e, I) 快速塌到 out=0 线上:

    out = Kp·e + Ki·I = 0  →  I = −(Kp/Ki)·e = −83.5·e

实测卡点 e=14.55°、I≈−1215(I/e≈−83.5),正躺在线上。
`Ki·I ≈ −21` 的负偏置持续扣减比例项,输出掉进静摩擦死区(<1 rpm)电机停转
→ 卡在 90 − 14.55 ≈ 75.45°,实测 **75.45** 。
之后仅靠 `+e·dt ≈ 0.13/周期` 回填,间歇性挣脱死区挪一步——极慢上爬。

### 2.5 两种带 I 配置对照(唯一差别 = 反算项)

| 配置 | 积分的遭遇 | 现象 |
|---|---|---|
| P+I(Kaw=0) | 饱和期正向累积、无修剪 | 快，残余正向积分 → 过冲，慢慢回落 |
| P+I+KAW=0.3 | 饱和期被抽穿钉死 −1250，之后只剩 e·dt 回填 | 慢，负偏置扣 P → 卡 ~75.45° |

现象相反、配置只差反算项 → 慢的根源:**饱和期抽得太狠 + 退饱和后没人拉回**。

## 3. 结论与规则

1. **大误差阶段禁用积分(积分分离)**。I 与 KAW 都是收尾工具，扛不住
   开场 40 周期的连续饱和:Kaw=0 → 正向 windup 过冲；Kaw≠0 → 积分被抽成
   负偏置、提前熄火卡死。如你需要积分且需要反计算法，则按误差门限切换:

    #define I_SEP_TH 15.0f          /* 误差小于线性区宽度才开始积分 /
    if (fabsf(error) < I_SEP_TH)
    pid->integrate += error * dt;   /* 大误差时积分冻结,只留 P 冲刺 */
   
2. **串级外环(位置环):纯 P**。本例静差 <0.2°,无需 I。
3. **消静差交给内环**:速度环误差小、少饱和，积分很安全。
4. 若外环确要加 I:积分分离 + 饱和冻结(条件积分)；慎用。
"反算 + 小 int_max"组合(本笔记即反面教材)。

> **外环 = 大误差 + 长饱和 = 积分高危区。I 和 KAW 是收尾的工具,不是开场的武器——开场要么积分分离,要么干脆纯 P。**
