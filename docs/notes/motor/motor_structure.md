# 有刷 vs 无刷电机结构自学

## 1. 初次了解（着重无刷）
有刷结构是线圈为转子，永磁体为定子，电刷不断翻转电流，线圈、电刷一起转，即电能换机性能（是内层转）。无刷是线圈为定子嵌在硅钢片（也是铁芯）上固定在内部圆环外层，永磁体为转子同样嵌在硅钢片上固定在外部的圆环内层（外层转）。了解到无刷电机上的定子与转子间隙非常的小（这些硅钢片都完美的集中导磁，不会相吸相斥外部的东西，比如地面上的金属等完美隔绝），通电后通过气隙导磁，让线圈与永磁体的相吸相斥，而线圈自身不会和自己相吸相斥是因为被固定绑死了，即便有吸力和排斥也动不了。而温度太高相应的也会脱磁，如钕铁硼永磁体在150°C量级开始不可逆的退磁，一般在150℃~200℃，超过区间则降温也无法恢复，车规电机靠液冷压制；桌面电机靠风冷+软件电流限幅，我的电流限幅PID算法里的 out_max 便是堵转保护的雏形.
- PS：这里把线圈当作内层，永磁铁作外层，无刷电机应用场景为新能源汽车电机.

## 2. 优化
| 我的说法 | 真相 | 为什么重要 |
|---|---|---|
| 硅钢片完美隔绝外部磁性 | 漏磁很小但**不为零**，吸铁屑确实存在 | 电动车电机防护设计须考虑 |
| 线圈被绑死所以不自斥 | 定子三相**互相有磁作用**，力被结构对称消化了 | 这是三相合成旋转磁场的物理基础 |

## 3. 个人所悟
- "有刷转线圈、无刷转磁铁" → 本质：**谁需要供电，谁就得有换流机制**
- 有刷靠机械电刷（磨损、火花）
- 无刷靠电子换向（必须知道转子在哪 → 有感/无感分野）
