# PI 调参坑：积分水库累积后难泄

## 一、现象
调 Ki 时撞了墙，每个值都有毛病：

| Ki | 现象 |
|----|------|
| 0.1 | 爬不到目标，卡在 43 附近不动 |
| 0.5 | 冲过 70，回收很慢，平均骑在 55~60 |
| 1 or 2 | 全幅扫掠，pwm 在 +100 / -100 之间来回剁，电机明显快速升温发烫 |
| 0 | 稳是稳了，但停在 7.97，静差 12 RPM，纯 P 补不上 |

当时第一反应是"Ki 太大了"，但往下试才发现：Ki 调到 0 才稳，说明问题不在 Ki 的大小。

## 二、根因链
分析出三个问题叠一起。

1. **换算系数用错了** 。当时把商家标的 35RPM 当成减速比，而 35 却是空载输出转速。该尺度下 1 count = 3.9RPM，低速端量化噪声相对误差 30%，误差信号基本被噪声淹没。
2. **积分没有"容量"概念** 。原代码 `int_max = out_max / Ki` ，积分能一路攒到等效 100% 占空比，但电机跑 20RPM 只要 ~54%。多攒的部分冲过目标后每 10ms 只能泄 `Ki × error × dt` ，从 90 泄到 16 要七八秒——这七八秒里 pwm 一直是正向大值，继续把电机往前推。
3. **输出是单向的，地板不够低** 。占空比只能 ≥ 0，环想要负力矩时给不出来，只能输出 0，干等摩擦把转速拖下来。
所以第 2、3 条一叠加就是全幅扫掠：冲过头 → 想拉回但没有负力矩，积分也泄不掉 → 转速被摩擦拖下来 → 攒满的积分再次发射。Ki 越大，这一圈越大。
PS:占空比和电机转速关系并非线性.

## 三、怎么修的 

### 3.1 先修结构：双向输出
符号走方向脚，绝对值走占空比：超调时可以主动反向拉一把，输出反向，不输出0干等。这是结构问题，必须在调参之前处理。
如：if (pwm_out >= 0.0f )duty = pwm_out ; else  duty = -pwm_out

### 3.2 采取措施————反计算法
原来的条件积分写的是"合成输出越界就冻结积分"。结果超调时合成输出变成负数，积分被冻在高位下不来——恰恰该泄的时候被锁死了。
反算法的思路：先算出**没限幅时本来想给多少**（out_unsat），再和被限幅后的实际输出（out）比，差值就是被削掉的那部分，按系数 Kaw 折算回积分域扣掉：

- 如：pid->integrate += error * dt+ pid->Kaw * (out - out_unsat) / pid->Ki
- PS:除以Ki是为量纲折算   out=Ki*integrate

1. 未饱和时 out == out_unsat，修正项为 0，就是普通积分；
2. 饱和时 (out - out_unsat) 是负数，把多攒的积分快速抽走；
3. 除以 Ki 是量纲折算：out = Ki × integrate，占空比域的差要变回积分域的差，就得除以 Ki。
它比"冻结"好在**主动泄**——两三个周期就把水抽到边界，而不是停在那等误差自己翻符号。

### 3.3 记一下抗饱和三代
| 代 | 方法 | 机制 | 局限 |
|---|---|---|---|
| 1 | 积分分离 | 误差大时禁积分 | 门槛难定，太窄会启动死锁 |
| 2 | 条件积分 | 往饱和方向推才冻结 | 只冻不泄，减的太慢 |
| 3 | 反算式 | 饱和时按 Kaw 主动抽走 | 多一个参数要调 |

## 四、结构性问题 vs 参数性问题
*调参之前先判断是哪种，不然白忙*

| 结构性问题 | 参数性问题 |
|---|---|
| 换算系数、反馈极性、输出是否双向、抗饱和机制 | Kp / Ki 的具体数值 |
| 调参数救不了 | 调参数能救 |
| 信号：增大减小都出现同类极端现象 | 信号：参数往一个方向调，现象单调改善 |

1. I 项最后上，起点取直觉值的 1/5；
2. 一次只动一个变量；
3. 振荡出现先减半；
