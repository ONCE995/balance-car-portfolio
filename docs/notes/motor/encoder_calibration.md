# 编码器标定：35 与 171

## 商家参数怎么读
- "35 RPM" = 空载输出轴转速（在内部马达近乎全速运行下），**不是减速比**
- "370" = 马达型号（直径 37mm）
- 减速比需要另外计算或实测

## 实测标定法（稳态驻点法）
1. 设 P-only（Ki=0），固定目标，读稳态转速和 pwm
2. 换另一个目标，再读一组
3. 用 `rpm = delta_count × 60 / (line × ratio × 4) / dt` 反推 ratio

## 严谨做法：双点独立测量 
编码器装在电机轴（减速箱之前），能直接读到电机侧转速，与减速比无关。
- 测点1（电机轴）：rpm _motor = Δcount × 60 / (11 × 4 × dt)
- 测点2（输出轴）：轴上贴标记，数 60 秒转了几圈（独立测量）
- 减速比 = rpm_ motor ÷ rpm _output

当前 171 是间接推算（马达额定 6000 ÷ 商家标称 35），不是独立测量；
自洽性证据：稳态 30RPM 实测 ≈38counts，与 171 推算的 37.6 吻合到 1count 内。
