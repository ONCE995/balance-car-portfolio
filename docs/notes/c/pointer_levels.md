## 2. 原理:传参的本质是拷贝副本
核心:**函数形参永远是副本**。副本本身改不动原件,
但副本如果是个地址,就能改到在该地址上的原件。

## 3. 数组名 ≠ 指针变量
- 数组名是"地址标签"(常量),就像电影院座位号被定在那里
- `frame + idx` 是"算出一个位置",并没有修改 frame.
    PS:如同更改手中的座位票从首位往后移动idx位。
- **sizeof 含义不同**:sizeof(frame)=36(整个数组),sizeof(p)=4(指针宽度)

### 双游标模式(JustFloat 里的实践)

- i = 读游标(源数组,指针加法按元素大小跳:float* + 1 = 地址+4)
- idx = 写游标(目标数组)
- 两个游标各自,互不干扰.类似环形缓冲、DMA搬运

## 4. "出参"

- `HAL_UART_Transmit(&huart1, ...)`:传 huart1 的地址,HAL 读配置+写状态
- **htim3/huart1 称句柄(Handle)**:一进一出,参数双向流通

## 6. 踩坑
- JustFloat 帧尾写成了 0x0D(\r)——正确是 00 00 80 7F(+∞),
  帧尾是给无边界的字节流"封口"的火漆
- 0x7F800000 按 IEEE754 解析 = 正无穷,正常数据永不等于它
